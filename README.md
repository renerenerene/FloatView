# FloatView

macOS用の、常に最前面に表示される軽量な画像閲覧アプリです。複数の画像を選ぶと、画像ごとに独立したウィンドウを開きます。

## 操作

- `⌘O`: 複数画像を開く
- `⌘+` / `⌘-`: 拡大 / 縮小
- `⌘0`: 実際のサイズ
- `⌘9`: ウィンドウに合わせる
- `⌘H`: すべての画像ウィンドウを表示 / 非表示
- `⌘T`: 選択中の画像へテキストを追加
- Finderから画像をドラッグ＆ドロップ
- 複数画像を一度に開くと、ディスプレイ内へ重ならないよう自動整列
- 「ウィンドウ」→「すべての画像を整列」でいつでも再整列
- すべての画像ウィンドウは常に最前面
- FloatView起動中に撮ったスクリーンショットを約0.8秒以内に自動で開く
- 初回に選択したスクリーンショット保存先の権限を保存し、確認の繰り返しを防止
- 保存先を変更した場合は「ファイル」→「スクリーンショット保存先を選択…」から再設定

追加したテキストはドラッグで移動、ダブルクリックまたは右クリックメニューから編集できます。右クリックの「文字サイズ」から8〜96ptの範囲で変更できます。ウィンドウ外までドラッグし、別の画像ウィンドウへドロップすると、文字とサイズを保ったまま移動します。空欄で編集を確定するか、右クリックメニューの「テキストを削除」で削除できます。

テキスト編集中の右クリックメニューは、カット・コピー・ペースト・すべてを選択・文字サイズ・編集終了だけを表示します。

## 開発用ビルド

```sh
./build_app.sh
```

完成したアプリは `outputs/FloatView.app` に作成されます。
